# Скиллы агентов

Скиллы лежат в `.claude/skills/<имя>/SKILL.md`. Их находят:
- **Claude Code** и вкладка Code в Claude desktop — вызов `/<имя>`, например `/kb-explore PM-04`, или своими словами;
- **OpenCode** — читает эту же папку; явный вызов — команды из `.opencode/commands/`.

Инструкция для людей — `kb/docs/skills.md`.

| Скилл | Когда | Кто обычно запускает |
|---|---|---|
| `kb-next` | Что мне делать дальше | Любой |
| `kb-init` | Новый репозиторий: команда, материалы или интервью по идее, `kb/product.md` | Аналитик, менеджер |
| `kb-map` | Черновик карты; пересборка одним пакетом по новым материалам и встречам (план «Было → Станет», `map apply`); подготовка шагов к взятию | Аналитик |
| `kb-take` | Посмотреть готовые к взятию руты и открытые карточки, взять рут, карточку или систему, вернуть | Разработчик, любой член пула |
| `kb-explore` | Разбор шага или карточки шага вместе с человеком: материалы, экспертиза роли, вопросы бизнесу; владелец нарезает большой шаг на карточки и принимает их; в конце — «Сверка с бизнесом» | Владелец рута, напарник, любой член пула через MR |
| `kb-interview` | Созвон с бизнесом: вопросы пула к одной роли (режимы А, Б); сверка рута PM-XX с бизнесом (режим В) | Аналитик; список для сверки готовит владелец рута |
| `kb-ask` | Задать вопрос без дублей | Любой |
| `kb-assume` | Оформить допущение, когда бизнес долго молчит | Владелец рута или декомпозита |
| `kb-answer` | Записать ответ, закрыть вопрос, подтвердить или опровергнуть допущение | Владелец шага переносит ответ в шаг; `ROOT` и руты без владельца — аналитик |
| `kb-decide` | Оформить решение: варианты, выбор, последствия | Любой предлагает, принимает архитектор недели |
| `kb-risk` | Завести или обновить риск | Любой |
| `kb-dataset` | Золотой датасет рута: матрица покрытия правил и исключений, случаи с реальными обезличенными данными и ожиданием из источника | Тестировщик — владелец или напарник рута |
| `kb-slice` | Нарезать рут на декомпозиты; нужен файл сверки `kb/materials/meetings/<дата>-sverka-PM-XX.md` | Владелец рута |
| `kb-accept` | Приёмка рута; ставит «Декомпозиты в работе» или возвращает | Архитектор недели (самоприёмка — техлид потока или предыдущий архитектор) |
| `kb-activity` | Кто что делал за период, где буксует процесс, что поправить в скиллах и правилах | Руководитель |
| `kb-sync` | Дежурство: ответы, дубли, противоречия, сроки, риски, дайджест, пакет для бизнеса | Дежурный по знаниям недели (`kb/team.md`), 2 раза в день |

Все скиллы опираются на `AGENTS.md` (режим работы, статусы рута, типы вопросов, кто что пишет), `kb/team.md` и `kb/tools/kb.py`.

Следующим этапом добавятся: спека, ревью спеки, план задач, приёмочные тесты, реализация.
