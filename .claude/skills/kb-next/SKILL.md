# Что делать дальше

Ничего не меняй в файлах. Только читай и подсказывай.

## 1. Кто работает

1. `python3 kb/tools/kb.py whoami` — имя, роли, стиль общения, режим, мои руты, **новые ответы**, вопросы, допущения, риски, незавершённое.
1а. `python3 kb/tools/kb.py resume` — журнал контекста: твои последние отправки с «Дальше» и что коллеги отправили после. «Дальше» из последней записи — первый кандидат на следующий шаг.
2. Имени нет в `kb/team.md` — `whoami` напечатал строку для аналитика: передай её человеку дословно. Если репозиторий только создан (`kb/product.md` пуст), следующий шаг — `/kb-init` (его ведёт аналитик).
3. **Сначала — новое для человека.** Первые строки ответа:
   - «НОВОЕ: пришли ответы на ваши вопросы» — перечисли ID и суть ответа одной фразой (открой файл вопроса, раздел «Ответ»). Дальше: ответ «ещё не перенесён в шаг» и человек — владелец рута (или аналитик для `ROOT`) — `/kb-answer Q-…`; иначе — что ответ перенесёт владелец рута, и что это меняет для человека;
   - «ВОПРОСЫ К ВАМ» — задай каждый человеку текстом вопроса (`python3 kb/tools/kb.py show Q-…`), а не номером. Знает ответ с источником — `/kb-answer Q-…`;
   - «НЕЗАВЕРШЁННОЕ» — `python3 kb/tools/kb.py resume`, покажи, на чём остановились, предложи продолжить.

## 2. Где продукт

Прочитай `kb/product.md`, `kb/context/process/_index.md`, `kb/journal/_index.md`. Если сводок нет или они старые — `python3 kb/tools/kb.py index` (для просмотра, в коммит не идёт), потом прочитай.

| Состояние | Следующий шаг для всех |
|---|---|
| `kb/product.md` пуст | `/kb-init` — аналитик |
| Карты нет (в `kb/context/process/` только PM-00) | `/kb-map` — аналитик |
| Руты в «Черновике», структура не сверена с бизнесом (нет строк в «Изменения структуры» или итогов сверки) | Сверка структуры с бизнесом — аналитик, `/kb-map` режим 1 §5 |
| Руты в «Черновике», структура сверена | `/kb-map` режим 3 — аналитик готовит шаги к взятию |
| Руты «Готов к взятию» | `/kb-take` — разработчики берут сами, по приоритету |
| Руты в «Разборе» | `/kb-explore` — владельцы и напарники |
| Руты в «Сверке с бизнесом» | Ждём созвон аналитика: `/kb-interview` режим В; владелец готовит список |
| `PM-00` без владельца, а в нарезках есть зависимости от него | Техлид потока: `take PM-00` |

## 3. Что лично у этого человека

Найди:
- руты и системы, где он владелец или напарник, и их статусы;
- вопросы, где он автор или подписчик;
- допущения, где он принял или проверяет, — особенно с близкой или прошедшей датой;
- риски, где он следит;
- если он архитектор недели — руты в статусе «Приёмка»;
- если он дежурный по знаниям (`kb/team.md`, поле `дежурный по знаниям`) — пора ли дежурство (`/kb-sync`): утро или после 15:00.

Для каждого — одна строка: что сделать и какой командой.

| Ситуация | Команда |
|---|---|
| Своих рутов меньше лимита из `kb/team.md` («Сверка с бизнесом» не считается), есть «Готов к взятию» | `/kb-take` |
| Рут в «Разборе» | `/kb-explore PM-XX` |
| `whoami`: «Мои карточки» | `/kb-explore PM-XX-KNN` |
| `whoami`: «Можно взять карточек» и место в лимите | `/kb-take` — `kb.py cards` |
| `whoami`: «карточки ждут вашей приёмки» | `python3 kb/tools/kb.py card accept PM-XX-KNN` — или `card return` с причиной |
| В руте пустые разделы, а материалов нет | `/kb-ask` — вопрос бизнесу; аналитик понесёт его на созвон |
| Рут в «Сверке с бизнесом», ты владелец, списка `…-sverka-PM-XX-plan.md` нет | `/kb-interview` режим В, шаг 1 — подготовить список для аналитика |
| Рут в «Сверке с бизнесом», ты аналитик | `/kb-interview` режим В — созвон |
| `whoami` показал «Ответы ждут переноса в ваш шаг» или «Ответы без хозяина» | `/kb-answer Q-…` |
| Аналитик, накопились вопросы к одной роли бизнеса | `/kb-interview` — созвон |
| Дежурный недели — ты | `/kb-sync` |
| Руководитель, конец недели или «как идёт процесс» | `/kb-activity` |
| Ищут напарника на рут (`kb.py ready`), а у вас есть место в лимите | `/kb-take PM-XX` |
| `whoami`: «НОВОЕ: пришли ответы» по вашему руту или `ROOT` (вы аналитик) | `/kb-answer Q-…` |
| Вопрос висит больше 2 рабочих дней и блокирует | `/kb-assume` |
| Файл сверки `…-sverka-PM-XX.md` есть, ответы перенесены | `/kb-slice PM-XX` |
| Рут в «Приёмке», вы архитектор недели | `/kb-accept PM-XX` |
| Допущение просрочено | Эскалация техлиду потока |

## 4. Если лично у человека ничего нет

Предложи `/kb-take` (`python3 kb/tools/kb.py ready` — что можно взять) и покажи открытые вопросы, на которые он может ответить по своей роли.

## 5. Ответ

Не больше 10 строк, тон — по стилю из `whoami`. Порядок: новое (ответы, незавершённое) → срочное и то, что блокирует других → остальное.
