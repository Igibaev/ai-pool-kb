# Отправить в develop

Все работают в одной ветке `develop`. Отправляет только `kb.py push`: он проверяет, обновляется, решает простые конфликты и печатает текст для группы. Сам `git push` не вызывай никогда.

**Без согласия человека не отправляй** (правило 10 `AGENTS.md`). Согласие — его собственное «отправь», «запушь», «влей» в этом сообщении или «да» на твой вопрос «Отправить в develop?». «Я закончил» и запуск скилла — не согласие. Одно согласие — одна отправка. Человека нет или он не ответил — не отправляй: оставь коммиты и скажи, что они ждут отправки.

## 1. Подготовить

1. `git status --short`. Есть незакоммиченные файлы:
   - свои — коммит по именам по правилу 6 `AGENTS.md`;
   - чужие или непонятные — спроси человека, не коммить.
2. Ветка не `develop` — спроси человека, что это за ветка. Без ответа не переноси коммиты.

## 2. Спросить

Покажи человеку `git log --oneline origin/develop..HEAD` — что уйдёт. Человек уже написал «отправь» — переходи к шагу 3. Иначе спроси: «Отправить в develop?». Ответ не «да» — остановись.

## 3. Отправить

Только с согласием: `python3 kb/tools/kb.py push`. Инструмент тоже спросит разрешение на эту команду: человек выбирает «Allow once» в OpenCode или «Yes» в Claude Code. Дальше — по коду возврата и словам в выводе:

| Вывод | Что делать |
|---|---|
| «Отправлено в develop» | Шаг 3 |
| «свежие правки коллег в ваших файлах», код 3 | Покажи человеку блок «В develop свежие правки…»: кто, когда, что поменял, будет ли конфликт. Спроси ещё раз, отправлять ли. Только после нового «да» — `kb.py push --yes` |
| «ВЗЯТО ДРУГИМ», код 5 | Рут или карточку успели взять раньше. Взятие уже отменено. Скажи, кто взял; предложи `/kb-take` — следующий |
| «НУЖЕН ЧЕЛОВЕК», код 4 | Покажи по каждому месту три версии: «было», «в develop», «у вас». Спроси: оставить версию develop, свою, обе или новую формулировку. **Не выбирай сам.** Исправь файл по ответу, убери отметки `<<<<<<<`, `\|\|\|\|\|\|\|`, `=======`, `>>>>>>>`. Покажи исправленную строку и спроси «Отправить?». Только после «да» — `kb.py push --continue` |
| «kb.py check: … ошибок N» | Исправь ошибки (`kb.py check` покажет строки), закоммить, снова `push` |
| Человек передумал посреди конфликта | `kb.py push --abort` — всё как до отправки |

## 4. Сказать команде

Вывод заканчивается блоком «Текст для группы». Покажи его человеку целиком и попроси переслать в чат команды. В нём новые факты, вопросы, руты «Готов к взятию» и новые карточки — по нему коллеги берут работу. Нужен снова — `python3 kb/tools/kb.py announce`.

Отчёт — до 5 строк: что отправлено, что открыто, следующий шаг.
