# Пул и агенты: кухня шаблона базы знаний

Процесс разработки под ИИ-агентов: один пул (разработчики, тестировщики, аналитики, веб), канбан, работа от спецификаций. Путь работы: карта процессов → руты (шаги карты) → декомпозиты → спеки → код.

**Сам шаблон — отдельный репозиторий [`Igibaev/kb-template`](https://github.com/Igibaev/kb-template).** Новый продукт и игра создаются из него; агента (OpenCode, Claude Code) запускают из его корня. Здесь — то, что не должно попадать в репозиторий продукта.

## Что здесь

```
sim/                         симуляция «Неделя в репозитории»: сценарий, сборка, экзамен модели
nedelya-v-repozitorii.html   готовая страница симуляции — открыть в браузере
game/                        ответы ведущего для игры (vedushchiy/) — игрокам и их агентам не показывать
agent/                       новый агент (ветка new-agent): корень будущей ветки context продукта
sborka-agenta/               сборка агента: порции, решения, покрытие требований — в продукт не переносится
```

Материалы игры для игроков (`game/<набор>/inbox/`) и правила игры (`game/README.md`) лежат в `kb-template`.

## Симуляция

Нужны Python 3.9+, git и клон `kb-template` рядом с этим репозиторием:

```
git clone https://github.com/Igibaev/kb-template
git clone https://github.com/igibaev/ai-pool-kb
cd ai-pool-kb/sim
python3 build.py              # другой путь к шаблону: SIM_TEMPLATE=/путь python3 build.py
```

Через 10–20 секунд появятся `sim/out/repo/` и `sim/out/nedelya-v-repozitorii.html`. Сборка после каждого события запускает `kb.py check` и останавливается на ошибке.

| Файл | Что в нём |
|---|---|
| `story.py` | События по порядку: правки файлов и коммиты |
| `dialogs.py` | Сессия с агентом для каждого события |
| `phrases.py` | «Можно сказать и так» к событиям и шпаргалка по скиллам |
| `exam.py` | Экзамен модели на двух шагах с автоматической оценкой |
| `player.tpl.html` | Шаблон страницы |

Тесты `tools/kb.py` — в `kb-template/tools/tests`.
