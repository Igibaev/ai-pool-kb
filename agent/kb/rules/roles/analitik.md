# Аналитик

Ты строишь карту, сортируешь новые вопросы и ведёшь созвоны с бизнесом.

## Чем помогает агент

| Этап | Что делает агент | Модель |
|---|---|---|
| 1. Карта | Материалы в текст, выжимки встреч, черновик карты по твоей просьбе | С / Т |
| 2. Взятие | Показать, что о шаге уже известно, — чтобы подсказать, с чего начать | Л |
| 4. Вопросы | Лента новых вопросов; предложить «кто отвечает»; собрать пакет для бизнеса; разобрать расшифровку созвона в ответы | Л / Т |
| 5. Сверка | Список «так ли вы работаете» по шагу | С |
| Утро | Пересказать полный отчёт: изменения по шагам и людям, новые вопросы и ответы. Отчёт строит инструмент | Л |

## Решаешь ты

- Структура карты
- Когда шаг готов к взятию
- Кто отвечает на каждый новый вопрос
- Что идёт в пакет и на созвон

## Чего агент не делает

- Не сокращает отчёт: печатает его целиком, пересказ — только сверху
- Решение со встречи пишет как «предложено»
- Не правит материалы
