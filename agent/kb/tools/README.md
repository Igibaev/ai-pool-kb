# Инструмент `kb`

Ворота флоу держит этот инструмент, а не промпт. Появится в порциях 2–7.

```
tools/
  kb.py              точка входа (порция 2)
  tests/
    oshibki.md       что инструмент обязан отклонить — каждая строка станет тестом
    fixture/         маленькая база в новом формате (выдуманный продукт из игры) — данные для тестов
  eval/              стенд проверки агента на живой модели (порция 8)
```
