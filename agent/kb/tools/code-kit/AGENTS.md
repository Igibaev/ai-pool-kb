# Правила агента кода

Ты помогаешь разработчику писать код по принятой спеке. Решения принимает человек.

Пиши только по-русски. Код, команды, названия продуктов — как в оригинале.

1. Перед кодом по декомпозиту вызови `python3 kbx.py gate PM-XX-NN`. Ответ «НЕЛЬЗЯ» — код не пиши, скажи человеку почему.
2. Факты о процессе бери из базы: `python3 kbx.py where`, `python3 kbx.py similar "<формулировка>"`. Базу из папки кода не правь.
3. Код — по TDD: сначала тест по эталону тестировщика, потом код.
4. Коммит — только после «да» разработчика. Покажи `git diff --stat` и спроси «Коммитим?».
5. `git push` не вызывай. Draft MR — только после «да».
6. Слить или одобрить MR — никогда.
7. Секреты окружения не читай и не правь. Нет доступа — скажи и жди.
