# Команда продукта (пример)

В примере вместо имён — роли с номером. В живой базе здесь имена людей пула, как в `git config user.name`.

| Имя | git | Роли в пуле |
|---|---|---|
| Аналитик | analyst@example.local | аналитик |
| Разработчик-1 | dev1@example.local | разработчик |
| Разработчик-2 | dev2@example.local | разработчик, техлид потока |
| Тестировщик-1 | qa1@example.local | тестировщик |
| Руководитель | lead@example.local | руководитель |
