# Золотой датасет

Реальные обезличенные случаи с ожидаемым результатом. Из них берутся цифры для сценариев спек и эталон для проверки системы.
Собирают тестировщики при разборе шагов карты процессов.

## Структура
```
datasets/
  PM-04/
    GD-PM-04-001.md
```

## Шаблон случая
```markdown
---
id: GD-PM-XX-NNN
шаг: PM-XX
тип: <обычный случай | исключение>
источник: <файл, строка, выгрузка — обезличено>
---
Вход: <данные>
Ожидаемый результат: <что должно получиться>
Откуда известно: <как это сделал человек или старый скрипт>
Статус ожидания: <подтверждено | допущение A-NNN>
```

## Правила
- Только обезличенные данные.
- Если ожидание взято из старого скрипта, а скрипт мог ошибаться, — статус «допущение».
- Каждый случай, найденный на бою и не покрытый сценариями, добавляется сюда.
