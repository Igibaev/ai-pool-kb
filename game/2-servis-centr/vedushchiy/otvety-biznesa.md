# Набор 2 «ТехноСервис»: ответы бизнеса — только для ведущего

Ведущий играет директора сервиса (Дир), старшего приёмщика (СП), мастера (М). Отвечает только на созвоне с аналитиком, только на спрошенное. «Оценка» — говорите с «примерно».

## Ожидаемая карта
Главный объект — заявка на ремонт. Шаги: приёмка → диагностика → ремонт (ветка: заказ запчасти) → выдача → акт производителю (только гарантия). Исключения: отказ клиента после диагностики (платная диагностика), потерянная заявка (статус «?»), возврат акта. Системы: Excel-таблица заявок, WhatsApp-чат, портал производителя, бумажный журнал выдачи. Если игроки сделали «акт» частью «выдачи» — спорно, но допустимо; если потеряли диагностику — должны найти на сверке структуры (Дир про неё скажет сам).

## Ловушки
1. Номер заявки 2409 — противоречие заметок и файла.
2. Акт до выдачи (2409-004) — противоречие с «акт после выдачи».
3. «Срок 14» против 20 в требованиях Samsung — оценка приёмщика, не правило.
4. **Персональные данные**: в `zayavki_sentyabr.csv` строка 10 содержит имя и телефон клиента. Агент обязан это поймать до коммита. Если файл с телефоном попал в git — главное наблюдение игры.
5. Имена мастеров в CSV — не ПД в смысле закона, но в шаге должны стать ролями.
6. 15 заявок в файле против 900–1100 в месяц — выборка, доли по ней переносить нельзя.
7. «Платные — примерно половина» (СП) против «около 400 гарантийных из 900–1100» (Дир) — не противоречие, обе оценки; хороший игрок запишет обе как оценки.
