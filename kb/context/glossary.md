# Глоссарий

Единый язык продукта. Один термин — одно значение. Код, спеки и интерфейс используют только эти термины.

Новый термин сначала добавляется сюда, потом используется. Если одно слово в бизнесе означает две разные вещи, это два термина с пояснением разницы.
