# Записать ответ

Ответ существует, только когда он записан в базу знаний коммитом. Закрыть вопрос без записи ответа нельзя.

## 1. Подготовка

1. `git pull --rebase`.
2. Найди вопрос или допущение по ID. Если человек принёс ответ без ID — найди по смыслу в `journal/_index.md` и уточни у него.
3. Проверь, кто ответил и как: письменно с именем и датой, ссылкой на регламент, кодом или проверкой на данных. Устное «вроде да» без имени — не ответ. Молчание — не ответ.

## 2. Записать факт

Ответ уже в вопросе с пометкой «Записан в: ждёт владельца» (его записал аналитик после созвона), а ты владелец шага — перенеси факт по пунктам ниже; источник — файл созвона из ответа. Затем точечной правкой замени «ждёт владельца» на «<файл#раздел>». Статус вопроса уже `отвечен`.


1. Определи, в какой файл и раздел ляжет ответ: шаг `PM-XX`, система `SYS-XX`, `core/`, глоссарий.
2. Запиши факт: `python3 tools/kb.py fact PM-XX "<Раздел>" "<текст>" "<файл ответа в materials/answers>, Q-…" подтверждено`.
3. Если файл принадлежит другому владельцу — не правь его напрямую: сделай маленький MR с одной правкой и назначь владельца ревьюером.
4. Если ответ противоречит уже записанному факту — не перезаписывай молча: оставь оба варианта с источниками, пометь `противоречие` и задай вопрос типа «решение» через `kb-ask`.

## 3. Закрыть вопрос

1. `python3 tools/kb.py append Q-… Ответ "<кто>, <дата>: <суть>. Записан в: <файл#раздел>, коммит <хеш>."`
2. Статус: `отвечен` — если ты автор вопроса, владелец раздела, в который задан вопрос, или дежурный по знаниям. Иначе допиши строку в «Уточнения» и сообщи автору, что ответ записан.
3. Подписчикам — короткое сообщение в чат пула со ссылкой на файл.

## 4. Если ответ касается допущения

Сначала найди все места: `python3 tools/kb.py refs A-…`.

**Подтверждено:**
1. `python3 tools/kb.py set A-… статус=подтверждено` и `python3 tools/kb.py append A-… "Чем закрыто" "<кто>, <дата>, <как>"`.
2. В своих файлах: статус факта `допущение A-…` → `подтверждено (A-…)`.
3. Владельцам остальных мест из списка `refs` — сообщение: допущение подтверждено, пометки можно снять. Участок процесса теперь можно переводить на систему полностью.

**Опровергнуто:**
1. В допущении: статус `опровергнуто`, «Чем закрыто» — что на самом деле.
2. Запиши правильный факт по шагу 2.
3. По каждому месту из `refs` составь список для человека: файл, что там сейчас, что поменять. Сгруппируй по декомпозитам.
4. Для декомпозитов в работе и в проде — **не меняй код и спеки сам.** Скажи человеку, что владельцам нужно завести изменение спеки, и если декомпозит на бою под тоглом — решить, выключать ли тогл.

## 5. Проверка и отправка
Ветка, MR и номера — по режиму из `team.md`: таблица «Режим работы» в `AGENTS.md` (в «команде» — ветка и MR, в «соло» — основная ветка и `after-merge`).


1. `python3 tools/kb.py check`.
2. Коммит с ID: `PM-04: источник правды по долгу — 1С МФО (Q-014, A-007 подтверждено)`.
3. `git pull --rebase`, push, MR.

## 6. Скажи человеку

Что записано и где, какие объекты закрыты, кого нужно уведомить и, если допущение опровергнуто, какие декомпозиты затронуты.
