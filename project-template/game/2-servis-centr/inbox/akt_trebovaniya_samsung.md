# Требования производителя к акту гарантийного ремонта (выдержка, Samsung, 2026)

1. Серийный номер изделия — обязателен, с фото шильдика.
2. Код дефекта по справочнику производителя (таблица кодов, 140 позиций).
3. Код выполненной работы и артикулы заменённых запчастей.
4. Дата приёма, дата ремонта, дата выдачи; срок ремонта не больше 20 дней, иначе требуется объяснение.
5. Подпись клиента о получении.
Акт подаётся через портал производителя до 5 числа следующего месяца. Акт с ошибкой возвращается на доработку, повторная подача — до 15 числа.
