# Код

Код всех сервисов лежит в этом репозитории рядом с контекстом и спеками, чтобы агент видел всё в одном месте.

```
services/
  <сервис>/
    RUNBOOK.md      как собрать, выкатить, откатить, что проверить после выкатки
    src/
    tests/
      acceptance/   приёмочные тесты из сценариев спек
```

## Правила
- Структура сервиса и стек фиксируются решением D-NNN до первого декомпозита.
- Приёмочные тесты называются как сценарии спеки: `PM-XX-NN_С1.1_<имя>`.
- Границы модулей проверяются автоматически в CI.
- RUNBOOK обязателен до первой выкатки. Выкатывает не автор: так сервис знают минимум двое.
