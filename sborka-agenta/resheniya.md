## Открытые вопросы

1. **«У меня есть проект».** Это база продукта с прошлой версией, 28 локальных коммитов? Если да, пришлите путь и ветку. Я сверю форматы с живыми файлами шагов до порции 2. Предлагаю: выложить ветку `context` в любой репозиторий только на чтение.
2. **Какие модели есть на самом деле.** Какая версия Qwen? Есть ли у Open WebUI выход как OpenAI-совместимый провайдер для OpenCode? Таблица — `04-modeli.md`, раздел «Что вписать».
3. **Draft MR через MCP GitLab** требует токена на запись. Бриф говорит: токен на запись в песочницу не давать. Варианты:
   - (а) Draft MR создаёт человек на хосте, агент готовит текст;
   - (б) токен с ролью Developer: защищённая ветка не даёт ему слить MR, это проверяет сервер.
   Предлагаю (б): запрет слияния тогда держит GitLab, а не модель.
4. **Ф1–Ф6** — согласны?
5. **Карточки шага (`process/cards/`).** Оставить рядом с `notes/` или заменить ими? Предлагаю пока не делать карточки. `notes/` закрывает находки без владения. Карточки нужны для параллельного разбора, а шаг по флоу берут один-два человека. [Likely] Вернём карточки, если шаги окажутся слишком большими для двоих.
6. **Логин латиницей** в именах файлов `notes/` — согласны?
